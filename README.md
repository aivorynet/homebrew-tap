# Homebrew tap of Aivory

```sh
brew install aivorynet/tap/aivory-code
```

Installs [AIVory Code](https://github.com/aivorynet/aivory-code) on macOS (Apple silicon and Intel)
and Linux (x64): `aivory`, the desktop app, and `aivoryd`, the daemon. Start it with `aivory`.

The formula is made by the release workflow of aivory-code (`packaging/render-packages.sh`).
